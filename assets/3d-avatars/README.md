This directory contains 3D avatar models in GLB format and their PNG preview images.

Expected files:
- male-business.glb + male-business.png
- female-business.glb + female-business.png
- male-casual.glb + male-casual.png
- female-casual.glb + female-casual.png

Each avatar should have both a GLB model file and a corresponding PNG preview image with the same base name.
