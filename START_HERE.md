# 🚀 Metaverse Hub - Start Here!

## 🎯 Quick Start (3 Steps)

### Step 1: Start the Server
**Option A - Automatic (Recommended):**
- Double-click `start.bat` file
- This will automatically start the server and open the application

**Option B - Manual:**
- Open Command Prompt in this folder
- Run: `python -m http.server 8000`
- Open browser and go to: `http://localhost:8000`

### Step 2: Verify Everything Works
- Go to: `http://localhost:8000/verify.html`
- Click "Run Full Verification"
- All tests should show green checkmarks ✅

### Step 3: Launch the Metaverse Hub
- Go to: `http://localhost:8000/index.html`
- Or click "Open Metaverse Hub" from the verification page

## 🎮 How to Use the Metaverse Hub

### 1. Create Your Avatar
- Click "Enter Room" on any room card
- Choose your avatar creation method:
  - **Upload Photo**: Upload your photo for AI-generated avatar
  - **Ready Player Me**: Use Ready Player Me service
  - **Preset Avatars**: Choose from available avatars

### 2. Explore the 3D Environment
- **Movement**: Use WASD keys to move around
- **Camera**: Switch between First Person, Third Person, and Free Look
- **Interactions**: Click on chairs, tables, and whiteboards

### 3. Earn Points & Unlock Avatars
- **Sitting in chairs**: +25 points
- **Using whiteboard**: +50 points
- **Starting meetings**: +100 points
- **AI avatar generation**: +50 points
- **Unlock premium avatars** as you earn more points!

### 4. Voice Chat & Meetings
- Click the microphone button to toggle voice chat
- Click the conference table to start meeting mode
- Use the whiteboard for collaborative drawing

## 🔧 Troubleshooting

If something doesn't work:

1. **Check the verification page**: `http://localhost:8000/verify.html`
2. **Read the troubleshooting guide**: `TROUBLESHOOTING.md`
3. **Check browser console**: Press F12 and look for errors
4. **Try a different browser**: Chrome or Firefox work best
