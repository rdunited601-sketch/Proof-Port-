## 🐛 **Known Issues & Solutions**

### **Issue**: "THREE is not defined"
**Solution**: Refresh the page, check internet connection for CDN

### **Issue**: Microphone not working
**Solution**: Allow microphone permissions, use HTTPS or localhost

### **Issue**: 3D environment not loading
**Solution**: Check WebGL support, try different browser

### **Issue**: Movement not working
**Solution**: Click on 3D canvas first to focus, then use WASD
